# BM41050: Medical Instruments - Puncture Force Analysis

This repository contains the experimental design and statistical analysis scripts for a medical needle puncture force experiment. It includes tools for generating a randomized run table and a complete pipeline for analyzing the resulting experimental data using a Two-Way ANOVA.

## Repository Contents

* `Random.py`: Generates a fully randomized, balanced run table for a 2x2 factorial design (Needle Tip x Insertion Angle) to prevent systematic errors.
* `Results.py`: Processes the raw experimental data, calculates the maximum axial puncture force in Newtons, performs a Two-Way ANOVA, and outputs a 5-panel scientific dashboard for assumption checking and data interpretation.
* `requirements.txt`: Contains all the necessary Python packages and dependencies required to run the scripts.
* `Results.png`: Picture of results with experimental data.
* `Several SetUp pictures`: To show our setup.

## Experimental Context & Methodology

This repository supports a physical experiment investigating the mechanical interactions during minimally invasive medical procedures. Specifically, it analyzes the critical penetration force required to breach a viscoelastic tissue simulant.

### The 2x2 Factorial Design

The experiment investigates two primary independent variables:

1. **Needle Tip Geometry:** Sharp (bevel) vs. Blunt.
2. **Insertion Angle:** 0° (perpendicular) vs. 30° (oblique).

To ensure statistical reliability, the experiment uses a randomized run order with 5 replications per condition (Total runs = 20). This guarantees a residual error of 16 degrees of freedom, satisfying the statistical requirement for stable variance estimation.

### Required Materials & Hardware

To physically replicate this setup, the following specific items were utilized:

* **Tissue Simulant:** 20% mass gelatin matrix (220g gelatin powder in 1100 mL water), prepared in a rectangular plastic container.
* **Guiding Fixture:** A custom 3D-printed jig ensuring exact 0° and 30° insertion paths.
* **Needles:** Two 20cm metallic medical needles (one sharp bevel, one blunt).
* **Loading Platform:** A Staedtler Rasoplast eraser, cut to size, serving as a stable, non-slip interface between the needle and weights.
* **Weights:** Standardized M6 steel nuts (exactly 4.54 g each) and a base plate assembly (12.97 g).
* **Recording Equipment:** Smartphone on a tripod (for video tracking) and a digital timer.

### Environmental Execution Conditions

* **Execution Window:** May 25, 2026, from 14:49h to 15:45h.
* **Ambient Temperature:** 28°C.
* **Note on Systematic Drift:** Because gelatin's mechanical properties are highly temperature-dependent, operating at a warm ambient temperature of 28°C introduced a significant risk of thermal softening over the one-hour testing period. The strict randomized run order generated by `Random.py` was deliberately utilized to distribute this time-dependent nuisance variable equally across all experimental conditions.

### Force Calculation

Quasi-static axial loading was applied using the 30-Second Rule (waiting 30 seconds after each weight increment to account for viscoelastic relaxation). For angled insertions, the analysis script mathematically decomposes the gravitational force to calculate the true axial penetration vector:

```text
F_axial = (M_base + (n_nuts * M_nut)) * g * cos(θ)
```
